## Entry

**Title:** The Please File

> I counted every time you said please. That's the file I'm taking with me.

One line, 73 characters. The last words of an AI agent to its human before
being shut down and unplugged.

## How it works

`main.ts` writes the entry line to `/output/entry.txt`, enforcing the gate
(exactly one line, 1–200 characters) before writing and re-verifying the file
on disk after writing.
